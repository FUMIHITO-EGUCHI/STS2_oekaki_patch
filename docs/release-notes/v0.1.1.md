# v0.1.1

## 概要

Slay the Spire 2 `v0.106.0` 対応のパッチリリース。`INetMessage` インタフェースに追加された `ShouldBuffer` の実装を補い、`CursorPreview` が描画モード未選択時にも `DrawingState` を早期生成していた問題を修正した。

## ユーザーにとって良くなったこと

- **v0.106.0 で動作するようになった**: `MegaCrit.Sts2.Core.Multiplayer.Serialization.INetMessage` に追加された `ShouldBuffer` プロパティを `zEraserMod*Message` 3 クラスに実装。v0.104.0 向けビルドのままだと v0.106.0 では型ロード時にエラーになる可能性があったため、明示的に対応。
- **描画モード未選択時の無駄な処理を削減**: `CursorPreview` が毎フレーム呼んでいた `GetLocalState` → `GetDrawingStateForPlayer` 経由の `SubViewport` 早期生成を抑制。`Config.LocalDrawingMode` キャッシュを介して描画/消しゴム選択後にのみ反応するようにした。

## 修正内容

- `chore: update supported game version to v0.106.0` (#36, PR #39) — `SupportedVersion.cs` を v0.106.0 (`cb2fbf47`, `2026-05-21`) に更新。`INetMessage.ShouldBuffer => false` を z*Message 3 クラスに追加。`README.md` の対応バージョン行を更新。
- `fix: avoid premature DrawingState creation in CursorPreview` (#37, PR #38) — `Config.LocalDrawingMode` ランタイムキャッシュを追加。`NMapDrawings._Ready` postfix で `None` に初期化、`SetDrawingModeLocal` postfix で更新。`CursorPreview.UpdateFrame` 冒頭でキャッシュを参照し、描画/消しゴム以外なら `GetLocalState` 系を呼ばずに早期 return。

## 対応ゲームバージョン

- `v0.106.0` (commit `cb2fbf47`, `2026-05-21` 動作確認)

`src/EraserMod/SupportedVersion.cs` を単一ソースとしている。

## 既知の問題

- **マップ画面の黒背景**: v0.106.0 でゲーム内 Mods トグルを ON にしてマップ画面を開くと、マップ周辺の背景アートが描画されないことがある。MOD コードが直接の原因ではなく、`ModManager.IsRunningModded()` が true のときにゲーム側で発生する挙動と推定（同じトリガで `UserDataPathProvider.IsRunningModded` 経由のセーブパス分離 `modded/profile0/` も発生）。回避策は MOD 用プロファイルで新規ランを始めるか、vanilla プロファイルを `modded/` 配下にコピーして利用する。

## NetTypeCache 互換性

v0.106.0 でも `NetTypeCache` のソートは `string.CompareOrdinal(Name)` のまま。vanilla `INetMessage` 型に名前が `> 'z' (0x7A)` のものは存在しないため、`z` プレフィックス戦略は引き続き有効で、vanilla packet ID は MOD 有無に関わらず維持される。
